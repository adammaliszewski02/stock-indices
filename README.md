# Stock Indices directory

Browse the company reports and charts generated by this project from a local searchable directory.

## Run locally

From the repository folder, start the app with Python:

```powershell
python app.py
```

Then open [http://127.0.0.1:8000](http://127.0.0.1:8000). The server listens on the loopback interface and serves the existing reports under `enterprises/`. Press `Ctrl+C` in the terminal to stop it.

Search by company name or ticker, use the US/Warsaw filters, or browse the directory. Selecting a result opens that company's existing HTML report, including its profile and charts.

## Run with Docker

Build the image and start the application with Docker Compose:

```powershell
docker compose up --build
```

Open [http://localhost:8000](http://localhost:8000). Compose bundles the existing `enterprises/` reports in the image. Stop the application with `Ctrl+C`, or run `docker compose down` in another terminal.
